@bitcode/ui-schema is the canonical, framework-neutral source of UI schema types and the headless reactive engine behind every BitCode renderer. It has no DOM dependency: reactions are pure functions over a value store, so the same definitions drive React, Vue, React Native, Flutter, and plain HTML.

Everything below runs client-side from the actual package source. Change a field and watch the declared reactions recompute.
